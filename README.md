# Arcane Labyrinth

A polished browser-based pixel roguelite dungeon crawler. Explore procedurally generated floors, defeat escalating enemies, choose build-defining upgrades, collect equipment, and conquer 20 unique guardians.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite.

## Controls

- `WASD` / arrow keys: move
- Mouse / `J`: aim and attack
- `Space`: dash
- `E`: open nearby chest
- `I` / `Escape`: equipment
- Gamepad: left stick moves, right stick attacks, A opens, B dashes

## Validation

```bash
npm run lint
npm run build
```

## Assets

Pixel sprites are from [Kenney's Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon), licensed CC0. Additional effects, UI, environments, and audio are generated at runtime.
